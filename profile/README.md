<h1 align="center">KESTRIL</h1>
<p align="center"><strong>Defense Technologies · Concept Studio</strong></p>
<p align="center">Observation · Sensing · Communications · Field Support</p>

---

Kestril is an independent defense technology concept studio based in Raleigh, North Carolina. We explore original concepts for unmanned observation, sensing, protective early warning, field communications and support equipment.

Our work combines engineering research, industrial design, editable 3D models and technical storytelling. Each study records its assumptions, constraints, open questions and proposed validation needs.

## Concept portfolio

| Program | Concept focus |
| --- | --- |
| **SD-02 ARGUS** | Portable observation station and flagship concept study |
| **SR-01 KESTREL** | Compact unmanned observation platform |
| **CN-03 RELAY** | Field communications node |
| **PW-04 AEGIS** | Protective early-warning kit |
| **FS-05 ATLAS** | Field support system |
| **K-14 RAVEN** | Long-endurance, unarmed fixed-wing surveillance aircraft in concept development |

## Development approach

We share concept development, design revisions, visual studies and the reasoning behind proposed systems. Work progresses from mission definition and configuration comparison to conceptual architecture, consistent visual production and technical presentation.

**Fictional concept studies. Images are visualizations. Performance and integration remain unvalidated.** The portfolio represents exploratory design work. Manufacturing, deployment, certification, customers and test history have yet to be established.
